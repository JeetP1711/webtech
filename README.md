# WebTech Mastery - Semester 3 Exam Learning Hub

A complete offline educational dashboard for B.Tech Web Technology mid-semester preparation.

## Run

Open `index.html` directly in any modern browser. No server, backend, database, Node.js, framework, or external dependency is required.

## Features

- 37 syllabus topics covering HTML, CSS, SASS, Bootstrap basics, and responsive design
- Dynamic lessons with definitions, syntax, code, explanation, output, mistakes, exam tips, revision, and mini tasks
- Interactive HTML/CSS playground with examples
- Visual demos for document structure, box model, positioning, Flexbox, Grid, SASS compilation, and responsive layouts
- Flashcards with flip, next, previous, shuffle, known, difficult, reset, and localStorage progress
- Quiz Center with topic, unit, full syllabus, weak topic, and random quiz modes
- Exam Mode with timer, question navigation, review marking, scoring, and weak-topic recommendations
- Progress tracking, achievements, dark mode, search, important questions, revision mode, and cheat sheets

## Storage

The app uses `localStorage` for theme preference, completed topics, quiz results, exam results, flashcard status, achievements, and last studied topic.
